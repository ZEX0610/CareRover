# 新云主机接入步骤（不传密码）

当前部署资料：Ubuntu 22.04、4 核 8 GB、公网 IP `<SERVER_PUBLIC_IP>`，系统盘和数据盘各 40 GB。登录截图曾含凭据；不要在仓库中保存或传送密码。

## 用户先完成

1. 在云平台重置 root 密码并检查登录审计。若发现异常，先停止公网部署、保留日志并重建主机；新密码不要发到聊天中。
2. 在云平台安全组中确认 SSH TCP 22 可从管理电脑访问。初始测试可暂时放行当前公网出口 IP，后续收窄；不要为排障长期开放 `0.0.0.0/0:22`。
3. 已将 **v2 公钥**追加到服务器 `/root/.ssh/authorized_keys`，指纹 `SHA256:fVmxnAa5NZIGY97iMlKELhu4qmjKaSUMo8mq/RPTIj8`；已验证公钥登录。当前实际使用的无口令私钥为 `C:\Users\new20\.ssh\carerover_remote_v2`，不进 Git、不得上传。项目 `.access` 下原始私钥误带两个引号字符口令，仅作为过渡备份；后续可从服务器授权列表移除 v1 公钥。
4. 公钥登录已可用，且服务器 SSH 密码认证已关闭；仍需在云平台安全组将 TCP 22 限制为管理来源。详见 [现场进度](REMOTE_SERVER_PROGRESS_2026-09-26.md)。

## 域名与 HTTPS

推荐购买一个普通域名并按云平台要求完成大陆网站备案，再将 `A` 记录指向公网 IP。浏览器麦克风必须由受信任 HTTPS 页面开启。若暂不买域名，也可评估 Let's Encrypt 的公网 IP 短期证书；证书约 6 天有效，需要 Certbot 新版本与自动续期测试，且不改变大陆网站备案义务。不要使用自签证书作家长手机长期入口。

## 代理接入后将执行

1. 只读盘点：系统版本、磁盘、时间、网络、现有账号/SSH、防火墙及服务，记录基线，不覆盖用户现有文件。
2. 安装运行时与最小依赖，检查 `npm ci` 和自动测试；创建独立服务账号，部署 `relay/` 到 `/opt/carerover/remote-hub/relay`，令牌放 `/etc/carerover/remote-hub.env`，不是 Git 仓库。
3. 配置可信 TLS 证书与 443 服务，验证家长手机 HTTPS 麦克风授权、家长登录、WSS 和测试音频；设置重启自恢复、证书续期、日志轮换、带宽/费用告警。
4. 完成模拟设备阶段后，才在备份当前两板固件和独立音频实测的基础上逐步开发板端上行并现场烧录。服务器上线不等于真实小车已具备通话。

公开安全组最终只需 HTTPS 443、必要时证书验证用 80；SSH 22 仅管理者来源 IP。不要把小车的 `192.168.4.1` 或 CAM 的 `192.168.4.2` 直接暴露到公网。
