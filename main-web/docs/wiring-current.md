# CareRover 当前模块接线记录

更新时间：2026-09-15  
适用固件：`stage5-follow` 主控 + `stream` CAM，115200 8N1。本文记录当前项目已经确认的 GPIO 分配和推荐供电方式；若现场改线，应同步修改本文和固件配置。

## 1. 电脑、主控与 CAM

| 连接 | 接线/设置 |
|---|---|
| 电脑 → 主控 ESP32-S3 | USB Type-C 数据线；当前 Windows 识别为 `COM6`，串口监视器 115200 baud、8-N-1、无流控 |
| 电脑 → CAM ESP32-S3 | USB Type-C 数据线；当前 Windows 识别为 `COM3`，串口监视器 115200 baud、8-N-1、无流控 |
| 主控 ↔ CAM UART | 主控 `GPIO18 (RX)` ← CAM `GPIO47 (TX)`；主控 `GPIO17 (TX)` → CAM `GPIO48 (RX)`；两板 `GND` 必须相连 |
| CAM 网络视频 | CAM 加入主控热点后使用 `192.168.4.2` 的 MJPEG `/stream`；主控托管网页和 WebSocket，地址通常为 `192.168.4.1` |

USB 只用于调试、供电和烧录。两板分别由独立电源供电时，UART 仍必须共地；不要把两个 5 V 输出端直接并联。

## 2. 主控 I²C 传感器与 OLED

主控使用两组互不占用 GPIO 的 I²C：OLED/MAX30102 一组硬件 I²C，MPU6050 使用 GPIO6/7 的独立软件 I²C。

### OLED（SSD1306）

| OLED 引脚 | 主控 |
|---|---|
| VCC | 3.3 V（按模块丝印允许 5 V 时也优先使用 3.3 V） |
| GND | 主控 GND |
| SDA | `GPIO4` |
| SCL | `GPIO5` |

常见地址为 `0x3C`（若模块为 `0x3D`，需按实际模块调整）。OLED 不与 MAX30102 共用 SDA/SCL，本项目采用独立 GPIO。

### MAX30102 心率/血氧

| MAX30102 引脚 | 主控 |
|---|---|
| VIN/VCC | 主控 3.3 V（不要向裸芯片输入 5 V） |
| GND | 主控 GND |
| SDA | `GPIO8` |
| SCL | `GPIO9` |
| INT（若模块引出） | 当前固件未使用，可悬空 |

设备地址为 `0x57`。手指测试时保持传感器与手指稳定贴合，串口/网页的 `health` 事件以 `valid`、`hr_valid`、`spo2_valid` 为准。

### MPU6050 六轴

| MPU6050 引脚 | 主控 |
|---|---|
| VCC | 主控 `3.3 V`（当前现场已改为主控 3.3 V） |
| GND | 主控 GND |
| SDA | `GPIO6` |
| SCL | `GPIO7` |
| AD0 | 悬空/低电平，默认地址 `0x68`；拉高则为 `0x69` |
| INT | 当前固件未使用，可悬空 |

开机后需保持车身静止约 5 秒完成校准。软件会报告 `imu_status.valid`、`calibrated` 和 `tilt_fault`；未校准或数据过期时禁止运动。

## 3. 四个 360° 舵机与全向轮

舵机信号由主控 GPIO 输出，舵机红线/电源必须来自独立稳定 5 V 电源模块，不能由 ESP32 3.3 V 供电。外部电源 `GND` 与主控 `GND` 相连，四路信号地以此为参考。

### 物理轮位和 GPIO

从车顶向下看，四个轮按顺时针排列为：

`GPIO10 → GPIO12 → GPIO11 → GPIO13`

对应软件轮位如下：

| 软件轮位 | 物理位置 | 舵机信号 GPIO | 运动轴 |
|---|---|---:|---|
| FL（左前） | 左上 | `GPIO10` | 前后滚动（纵向） |
| FR（右前） | 右上 | `GPIO12` | 左右滚动（横向） |
| RR（右后） | 右下 | `GPIO11` | 前后滚动（纵向） |
| RL（左后） | 左下 | `GPIO13` | 左右滚动（横向） |

当前运动学约定：`vx` 正值为前进、`vy` 正值为向右横移、`wz` 正值为从上往下看顺时针原地旋转。GPIO10/11 是纵向主动轮对，GPIO12/13 是横向主动轮对，其他轮在相应方向上从动。

### 舵机电源

| 舵机线 | 连接 |
|---|---|
| 红线（V+） | 外部 5 V 电源正极 |
| 棕/黑线（GND） | 外部电源 GND；与主控 GND 共地 |
| 橙/黄线（信号） | 分别接 GPIO10、12、11、13 |

外部电源的额定电流和峰值能力需现场确认；四个舵机启动/堵转电流可能造成电压跌落。调试烧录和传感器测试阶段先断开舵机 5 V；运动测试时先架空车轮并确保急停可达。

## 4. CAM 摄像头内部引脚（CAM 板内部，不接主控）

CAM 固件使用的摄像头排线 GPIO 如下，普通使用者不需要另接杜邦线：

| 信号 | GPIO |
|---|---:|
| XCLK | 15 |
| SCCB SDA/SIOD | 4 |
| SCCB SCL/SIOC | 5 |
| D0…D7 | 11、9、8、10、12、18、17、16 |
| VSYNC / HREF / PCLK | 6 / 7 / 13 |
| PWDN / RESET | 未使用（-1） |

这些引脚属于 CAM 摄像头接口，不能拿来替代主控上的 OLED、MAX30102、MPU6050 或舵机接线。

## 5. 总体公共地和供电拓扑

```text
外部 5 V 电源 ── 舵机 V+（四路）
                 └─（必要时）CAM 5 V 输入
外部电源 GND ──── 主控 GND ── CAM GND ── 传感器/OLED GND
主控 3.3 V ────── MPU6050、MAX30102、OLED VCC
主控 USB-C ────── 电脑（COM6）
CAM USB-C ─────── 电脑（COM3）或独立 5 V 供电
主控 GPIO17/18 ── CAM GPIO48/47（TX/RX 交叉）
```

若主控不再连接电脑而改用电源模块独立供电，仍保持主控与 CAM 的 UART 线和公共 GND；网页改由连接 `CareRover-EE68` 热点的手机/电脑访问。任何改线后先断开舵机 5 V，再做 I²C 扫描和串口验证。

## 6. HC-SR04 超声波（推荐接线，引脚待现场确认）

HC-SR04 尚未现场实测，以下是推荐接线与硬性约束；**必须先核对具体开发板是否引出/占用，再按实际引脚接线**，不能直接照抄示例值。

| HC-SR04 引脚 | 连接 | 说明 |
|---|---|---|
| VCC | 5 V | HC-SR04 需 5 V 供电（可用外部 5 V 或 USB 5 V） |
| GND | 主控 GND | 必须与主控、传感器共地 |
| Trig | 允许 GPIO 之一，推荐 `GPIO14` | 输出，3.3 V 触发电平（至少 10 µs）；需确认模块对 3.3 V 触发有响应 |
| Echo | 允许 GPIO 之一，推荐 `GPIO15` | 输入；**Echo 是 5 V 电平，必须经分压（如 1 kΩ/2 kΩ）或电平转换降到 3.3 V，禁止直连 3.3 V GPIO** |

软件允许的 Trig/Echo GPIO 为 `1 / 2 / 14 / 15 / 16 / 21 / 38–42`；禁止占用：CAM UART 17/18、OLED 4/5、IMU 6/7、MAX30102 8/9、舵机 10–13、USB 19/20、启动/Flash/PSRAM 引脚。

接入步骤：复制 `firmware/main_wireless/front_config.example.h` 为 `front_config.local.h`，填 `trig`/`echo` 与 `control.enabled=true`，阈值按实测填写 `stopCm < slowCm <= warnCm <= 400`、`slowCm < releaseCm <= 400` 及绕障参数；`verified` 待实测后再置真。该私有文件不提交 Git。

## 7. 当前未纳入本表的接口

- 舵机没有编码器反馈，网页速度是控制量，不是实际轮速。
- CAM 与主控的 USB 可以只保留供电/调试用途；无线演示时不要求 CAM USB 连接电脑，但 UART 共地和 CAM 独立供电仍需保留。
