### 连续运行观察

最终页面在 1920×1080 内嵌 Chromium 中实际连续运行 312 秒，浏览器 Mock 以 50 Hz 产生 PPG。调试面板读取结果如下；JS 堆数值来自 Chromium 的近似 `performance.memory` 指标。

| 运行时间 | PPG 缓冲 | 界面 FPS | JS 堆 |
| --- | --- | --- | --- |
| 启动 | 10 / 4096 | 初始化 | 21.4 MiB |
| 199 秒 | 4096 / 4096 | 49 | 23.3 MiB |
| 237 秒 | 4096 / 4096 | 48 | 21.3 MiB |
| 291 秒 | 4096 / 4096 | 50 | 22.2 MiB |
| 312 秒 | 4096 / 4096 | 56 | 21.1 MiB |

缓冲保持固定容量，采样点未观察到堆持续增长，波形与遥测正常更新；本次运行无控制台错误或警告。FPS 为当前自动化内嵌浏览器读数，并非所有设备的性能保证。

## 明确边界

- 触摸以 Pointer Events 输入路径和移动视口检查覆盖；尚未在实体手机上做手指拖动验收。
- 五分钟样本测试、实际持续运行和定时器检查提供容量与运行观察；近似堆读数不是完整浏览器内存剖析报告。
- 本地测试视频用于播放和坐标检查，不代表真实人物检测。
- 尚未验证 ESP32 固件、真实传感器、物理急停距离、串口链路或实际网络性能。硬件到货后按下面清单继续。
