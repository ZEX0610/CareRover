# CareRover 设计约定

把它设计成精密设备的控制台。视野、运动和生命体征是主角，调试信息按需展开。

- 石墨背景和温和提亮的表面。主要文本接近白色，标签保持足够可读，不用低对比度制造“高级感”。
- 系统字体，数字采用 tabular-nums。中文与英文共享同一空间关系。
- 检测框使用蓝色，健康波形使用淡青绿色；红色集中于急停和故障。
- 顶部状态标题、主摄像头、控制输入、健康数字、设备详情依次建立阅读层级。
- 桌面视野与摇杆相邻；手机先展示视野再展示控制。模式和急停固定底部，正文有足够底部留白。
- 模式选中用轻色实体表面，pending 用颜色和微弱呼吸反馈。只有确认后的 mode 才显示选中。
- 摇杆归中有短缓动，拖动时直接跟手。系统“减少动态效果”偏好禁用 CSS 动画。
- 画面源和模拟标签明确，空数据用破折号。真实数据无效时不以模拟值填充。

前端不包含营销弹窗、夸张渐变、装饰性发光、无意义百分比或远程字体。素材均由项目代码生成，无外网依赖。
