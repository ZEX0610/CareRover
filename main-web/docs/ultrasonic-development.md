# HC-SR04 前方保护与固定向右绕障

本次实现为软件集成；主机测试/ESP32 编译不等于实物通过。单个探头固定朝前，只用于预先清空右侧和出口的单障碍演示。没有侧后方感知、编码器里程计、自动选路或回线保证。CAM 继续负责人脸与手势，主控负责本地测距、网页和安全仲裁。

## 软件行为

- 主控每 70 ms 触发一次 10 µs 脉冲；独立任务收取 ISR 记录的 Echo 边沿，不使用 `pulseIn` 等阻塞等待。无回波 30 ms 超时；Echo 卡高不会继续触发。有效脉宽对应 2–400 cm。
- 最近三个有效读数的中位数用于显示与减速；原始近距有效读数直接停车。无效值立即清空滤波，220 ms 没有新有效采样时禁止运动。无回波是未知，不是无限远。
- 安装配置缺省为未接入。显式启用后，未验证保护参数/引脚时拒绝运动；仍允许 observe 采样。安装采用 `front_config.local.h`，不在网页上改安全参数。
- 手动前进按 stop/slow 阈值限制 vx；到 stop 距离将整个目标归零并锁住输入。持续非零指令返回 `FRONT_RELEASE_REQUIRED`。收到操作者零命令后解锁；前进恢复还要求连续三个读数超过 release 阈值，避免临界距离反复启停，新前进指令仍受障碍保护；低速倒退由操作者确认后操作，不代表后方可见。测距故障退出到 IDLE，恢复测距后需重新选择模式。
- 跟随中的近障停车在主控执行。演示开关默认关闭，只允许跟随的控制者在绕障参数已验证时启用。一次绕障完成或退出后自动关闭；重新演示需再次启用。
- 流程：HALT 停车等待至少三个连续近距样本且达到实测停车等待时间 → RIGHT 右移直到三个连续样本超过释放阈值 → MARGIN 追加车身横移余量 → PASS 直行越过 → REACQUIRE 停车重置人脸跟随参考，等待三个新的合格匹配框 → 恢复跟随。
- MARGIN 中重新被挡则回 RIGHT，累计横移超时不重置。PASS 再进入减速区即退出停车。HALT 不稳定或 REACQUIRE 三秒未完成也退出停车。
- 原安全规则全程有效：目标丢失/匹配失败、CAM 超时、控制者保活超时、跟随输出过期、IMU 无效/倾斜、断网和急停都会取消绕障。停止不经舵机缓动，使用各轮校准中值；这不是主动机械制动。
- OLED 每两秒交替显示原有健康/手势数据与前方距离、保护状态、绕障阶段、停车原因。`front_status` 串口诊断带距离有效性、来源年龄、阶段、停车原因、同期 IMU yaw，可由现有 capture/analyze 工具记录。无效串口距离为 -1，必须结合 valid；网页使用 null。

## 接线与实物标定

1. 核对主板型号、可用 GPIO、5 V 电源与公共地。VCC 接 5 V，Echo 经分压/电平转换接 3.3 V GPIO，不能直连 5 V Echo。Trig 至少 10 µs；核实实际模块对 3.3 V 触发电平的响应。
2. 从 `firmware/main_wireless/front_config.example.h` 复制为同目录 `front_config.local.h`。填写实际 Trig/Echo 引脚。软件只允许 GPIO 1/2/14/15/16/21/38–42，仍必须检查具体开发板是否引出/占用。禁止占用 CAM UART17/18、OLED4/5、IMU6/7、MAX30102 8/9、轮子10–13、USB19/20、启动及 Flash/PSRAM 引脚。
3. 固定探头使声束避开轮子、车壳和地面，并能照到演示障碍的平整反射面。绕开后仍需有在 4 m 量程内、距离超过释放阈值的有效背景回波（例如远处墙面）；完全空旷无回波时会按未知停车，不会凭空宣布前方畅通。记录安装高度、探头相对车身最前缘的偏移、整车宽度及障碍宽度/深度。说明书的约 15°测角不是车身全宽覆盖；薄杆、斜面或回波不足都不能作为通畅依据。
4. 使用 observe 构建，`enabled=true`、`verified=false`，检查已知距离、近距、无回波/断开和所有旧传感器工作。设置参数值不会自动取得实物验证标记。
5. 用架空校准后的底盘实测最大演示前进速度、请求停止到中值输出延迟、输出后机械滑行距离。停车距离至少覆盖采样等待、处理延迟、机械滑行、探头至车身前缘偏移和余量。归一化 vx 不是 m/s；不填造假的停车厘米值。
6. 填写 `stopCm < slowCm <= warnCm <= 400`，`slowCm < releaseCm <= 400`。安装与阈值已有实测依据后，保存记录并将 `verified=true`，开放聚合固件的手动保护验收，再做停车、释放、恢复测试；这个标记不是验收 PASS，失败需撤销并修正。未开放时可用已有独立底盘校准工程在操作者控制的空场测量基线速度/停车性能。
7. 右侧/出口留出完整车身通道；固定障碍与地面。实测 `settleMs`（70–5000 ms）、`lateralSpeed/forwardSpeed`（0–0.25 范围内的非零归一化值）、`marginMs`、`passMs` 和 `lateralTimeoutMs`。总横移上限最多 30 秒且大于余量时间；前进最多 30 秒。实际参数应尽量短，由场地测量确定。
8. 先通过操作者控制的低速单独动作取得余量/越过时间等参数，记录真实依据后设置 `bypassVerified=true`，再开放集成绕障验收，重复验证车身边缘完全让开、直行越过后恢复跟随，并完成失败矩阵；失败应撤销标记。标定记录用 `config/calibration/front-template.json` 的本地副本，null 必须保持到实测完成。

缺省工程没有实物引脚和标定值；不会因为网页勾选而自动开放未验证硬件。私有安装头被 Git 与发布包排除，但设备构建会复制并计入内容指纹。设备更换/场地或障碍变化后重新标定，不能复用模拟数值。

## 网页与模拟演示

- 机器人状态中查看“前方障碍距离”、保护状态、阶段和停车记录。切到跟随，再开启“演示绕障 · 固定向右”。开关以设备遥测确认，非操作者/回放/失联时不可用。
- 浏览器 Mock：`python3 -m http.server 8080 --bind 127.0.0.1`，打开 `http://127.0.0.1:8080/?transport=mock`。
- Python Mock：`.venv/bin/python mock/server.py`，打开 `http://127.0.0.1:8080/?transport=ws&video=canvas`。Windows 使用 `.venv\Scripts\python.exe`。
- 两种模拟器开启演示后都自动生成一个前方障碍，展示全部阶段，然后恢复跟随并关闭开关。模拟采用 20/50/60/70 cm 阈值、0.15 速度、210/400/800 ms 时长、4 秒横移上限；这些仅存在于模拟器和测试，绝不作为真实标定。
- 测距近障使用醒目颜色和文本报警（含 aria-live），没有添加蜂鸣器硬件或依赖浏览器自动播放声音。

所有实物项目目前 **NOT RUN**：接线与电平、安装/障碍尺寸、实测速度与停车距离、横移余量/越过时间、不同表面回波、前方突然出现物体、侧方有人禁止启动、车身完整通过、目标丢失、再遇障、拔掉探头、断网、急停、健康/OLED/视频并行及十分钟稳定性。参考原有 Windows 联调顺序先备份再烧录，不将上述软件通过记录为实物通过。

本地历史参考包保持原样，源码提交不包含其中的恢复固件/素材。当前 firmware、构建依赖锁和测试可独立工作；GitHub checkout 无需依赖本地参考目录。
